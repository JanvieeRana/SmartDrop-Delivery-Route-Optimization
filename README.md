# SmartDrop – Delivery Route Optimization

E-commerce delivery route optimization using Nearest Neighbor, 2-Opt and Brute Force algorithms, with a Tkinter dashboard and Matplotlib route plot.

## Features
- Distance matrix built from warehouse and customer coordinates
- Nearest Neighbor heuristic for an initial route
- 2-Opt optimization to improve that route
- Brute Force search to find the exact shortest route
- Comparison of route distance and execution time for each algorithm
- Tkinter dashboard and Matplotlib route graph

## Requirements
- Python 3.x
- matplotlib (`pip install matplotlib`); Tkinter is included with Python

## How to Run
    python smartdrop.py

Click **Calculate Best Route** to see the results and **View Route Graph** to plot the best route.
